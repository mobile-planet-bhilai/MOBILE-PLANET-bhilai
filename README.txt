MOBILE PLANET BHILAI WEBSITE

FILES
- index.html: website structure and content
- style.css: design and responsive layout
- script.js: mobile navigation and current year
- assets/: supplied shop logo and product/store photographs

HOW TO VIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to preview in your browser.

HOW TO EDIT
- Change text, sections and links in index.html.
- Change colours and layout in style.css.
- Replace photos in assets/ while keeping the same filenames, or update image paths in index.html.
